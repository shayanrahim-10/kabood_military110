# هم‌راه — شروع‌کننده PWA

این پوشه یک نمونه اولیه قابل اجرا از رابط فارسی راست‌چین است. شامل پیشخوان، مدیریت آزمایشی کاربران، مکاتبات، انتخاب گیرنده، پاسخ، وضعیت مشاهده، سوابق، manifest و service worker است.

## اجرای سریع
1. فایل‌ها را روی یک میزبان HTTPS یا لوکال‌سرور استاتیک قرار دهید.
2. برای تست رابط، «مشاهده نسخه نمایشی» را بزنید.
3. در نسخه نمایشی داده‌ها در localStorage مرورگر ذخیره می‌شوند؛ این داده‌ها آنلاین یا مشترک بین دستگاه‌ها نیستند.
4. برای PWA، سایت باید روی HTTPS ارائه شود (به‌جز localhost).

## تبدیل به سامانه آنلاین واقعی
- یک پروژه Supabase بسازید.
- محتوای `supabase_schema.sql` را در SQL Editor اجرا کنید.
- اولین مدیر را از طریق Supabase Auth ایجاد کنید و سپس نقش او را با حساب مالک پروژه به `admin` ارتقا دهید.
- ایجاد کاربر توسط مدیر باید از طریق Edge Function سمت سرور و با کنترل نقش مدیر انجام شود. کلید `service_role` را هرگز در مرورگر قرار ندهید.
- پیام‌ها، گیرندگان، پاسخ‌ها و سوابق را از جداول Supabase بخوانید/بنویسید.
- فایل‌های پیوست را در Storage خصوصی قرار دهید و لینک امضاشده کوتاه‌مدت صادر کنید.
- برای اعلان لحظه‌ای از Realtime و برای اعلان خارج از برنامه از Web Push استفاده کنید.
- رمزها فقط توسط Supabase Auth مدیریت شوند؛ رمز خام را در دیتابیس یا گزارش‌ها ذخیره نکنید.

## محدودیت نسخه فعلی
این نسخه «نمونه رابط و گردش کار» است، نه سامانه آنلاین عملیاتی. ورود واقعی، همگام‌سازی چندکاربره، اعلان Push، آپلود امن فایل و ایجاد حساب واقعی تا اتصال بک‌اند فعال نیستند. اطلاعات نمونه ساختگی‌اند و نباید برای اطلاعات واقعی اشخاص استفاده شوند.
